# Explainable-ResBRNet-for-Brain-Tumor-Classification
Research-oriented deep learning implementation of an enhanced ResBRNet with explainability for brain tumor classification on the Figshare MRI dataset.
## Dataset

This project uses the Brain Tumor MRI Dataset available on Figshare:
https://figshare.com/articles/dataset/brain_tumor_dataset/1512427

The dataset contains 3,064 T1-weighted contrast-enhanced MRI images from 233 patients across three tumor types.
